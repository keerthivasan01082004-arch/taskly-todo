# Taskly Todo Application

## Overview

Taskly is a full-stack Todo Management application developed using **React.js**, **Node.js**, and **Express.js**. The application enables users to efficiently manage daily tasks with features such as creating, updating, deleting, searching, filtering, and organizing todos.

---

# Features

## Create Todo

* Create a new task with title and description.
* Assign task priority (Low, Medium, High).
* Set task status (Pending, In Progress, Done).

## View Todos

* Display all created tasks.
* View task information in a clean dashboard.

## Update Todo

* Edit existing tasks.
* Modify title, description, priority, and status.

## Delete Todo

* Remove unwanted tasks permanently.

## Search Functionality

* Search tasks using keywords.
* Dynamic search results.

## Filter Tasks

* Filter by Status.
* Filter by Priority.

## Sorting

* Display newest tasks first.
* Organize tasks efficiently.

## Dashboard Statistics

The dashboard displays:

* Total Tasks
* Pending Tasks
* In Progress Tasks
* Completed Tasks

## Responsive User Interface

* Modern dark theme.
* User-friendly interface.
* Responsive layout.

# Running the Project

## Backend

```bash
cd backend
npm install
npm start
```

Runs at:

```
http://localhost:5000
```

## Frontend

```bash
cd frontend
npm install
npm start
```

Runs at:

```
http://localhost:3000
```
